CarBid on the web

Every screen below is the desktop counterpart of a mobile Stitch design, built on CarBid's existing tokens — #135bec on #101622, 8px radii, Manrope's role filled by a geometric system stack. Desktop is not the mobile layout made wider: the bottom tab bar becomes a persistent left rail, the filter sheet stops being a modal, and stacked lease cards become a real comparison table. All screens show the four resolved decisions — CarBid branding, the blue system, plain dollar amounts, and the four-step sell wizard.

About this translation

Nineteen web screens from eighteen mobile designs — the extra one is the sell wizard's step 3, which never existed on mobile. Every screen uses CarBid's own tokens rather than a new visual identity, and all four resolved decisions are applied throughout: CarBid branding, the blue #135bec system, plain dollar amounts, and the four-step wizard.

  • Manrope substitution. The design system specifies Manrope. Font CDNs are blocked here and no binary was available to inline, so a geometric system stack stands in. Swap in the real face for production.
  • Photography is placeholder. Vehicle imagery is rendered as gradient blocks with labels; no stock or generated photography is implied.
  • Dark by design, not by default. All 18 mobile screens are dark and the design system declares DARK, so the product screens stay dark in both themes. Only the review chrome around them follows your OS light/dark preference.
  • Layout target is 1440px. Screens reflow down to roughly 760px, below which the product nav collapses to a horizontal strip. They are not a substitute for a genuine mobile breakpoint — that is what the Stitch designs are.
  • Some gaps are answered here, deliberately. Payment capture, wire references, ingest error handling, message threads and lease-limit enforcement are drawn because the flows are incoherent without them. Each is a proposal for review, not a settled decision — see REQUIREMENTS.md §12.
